# ٦٠ مشروع تخرج — نظم المعلومات الإدارية

مجموعة من **٦٠ فكرة مشروع تخرج** لتخصص نظم المعلومات الإدارية، مقسمة إلى مسارين:

- 🌱 **Green AI** — ٣٠ مشروع (الذكاء الاصطناعي الأخضر)
- 💼 **AI Business** — ٣٠ مشروع (الذكاء الاصطناعي للأعمال)

## المميزات
- كل المشاريع **Software فقط (Web / Mobile)** — بدون هاردوير أو إنترنت أشياء.
- كل مشروع يحتوي على ميزة AI حقيقية ومتصلة بالمشكلة الأساسية.
- شرح موسّع وموحّد لكل مشروع يشمل:
  - المنصة والمستخدمين المستهدفين.
  - المشكلة والفكرة بالتفصيل.
  - سيناريو التشغيل ورحلة المستخدم.
  - الوظائف الأساسية للنظام.
  - دور الذكاء الاصطناعي والبيانات المطلوبة.
  - المخرجات والقيمة الإدارية أو البيئية.
  - نسخة MVP قابلة للتنفيذ.
  - التقنيات المقترحة ومؤشرات قياس النجاح.
- تصنيف المشاريع حسب الصعوبة، ونموذج تقييم أكاديمي، ومتطلبات مشتركة لكل فريق.
